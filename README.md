## Что это

Мастер-проект: принимает трекинг BlackTrax, пересчитывает позиции гостей в единицы зон и (дальше) раздаёт тайминг, команды и данные на компы зон (слейвы).

## Две группы в тоннеле: сессии, гости, промпты

Пока группа одна, «гость 2» однозначен. Как только первая группа дошла до зоны 3 и заходит вторая — нет: гости нумеруются 1/2/3 **внутри своей группы**, а трекинг знает только физический ID бикона. Развязка:

- **Номер сессии** (`Sessionnum`, инкремент) — для людей, логов и адресации зонам; **uuid** — для сверки с панелью. Обе живут в `active_sessions`.
- **`assignments`: бикон → (сессия, гость 1..3)** — привязка живёт от входа до выхода гостя из тоннеля, потом бикон свободен для следующей группы.
- **Лимит** одновременных групп — `Maxactive` (по умолчанию 2). Гейт не пустит новую сверх лимита, даже если зоны 1–2 пусты.

Режим привязки — `Assignmode` (переключается кнопкой **ПРИВЯЗКА** в пульте):

| Режим | Как назначается гость |
|---|---|
| `auto` | Первый вошедший в зону входа → гость 1, второй → гость 2. Порядок перепутали — кнопки **СВАП** в пульте. |
| `pool` | Биконы закреплены за слотами (`beacon_pools`: A = 1,2,3; B = 4,5,6), слоты чередуются между группами. Гость = позиция бикона в своём пуле. |
| `manual` | Только оператором: `AssignBeacon(beacon, num, guest)` или кнопки пульта. |

Сессия закрывается сама, когда все её биконы вне зон дольше `Exitgrace` (8 с): биконы освобождаются, зонам уходит `/show/session/end`. Сводка активных групп с гостями, биконами, зонами и промптами — колонка **ГРУППЫ В ТОННЕЛЕ** в пульте.

## Потоки мастер ↔ зоны

Мастер → зоне N (`:10000`):

- `/show/clock`, `/show/state`, `/show/reset|finish|ping`
- `/show/session/start [num uuid guests]` — состав группы (шлётся при каждой правке привязок)
- `/show/session/prompt [num guest beacon promptid topicid text]` — чей промпт
- `/show/session/end [num]` — группа вышла из тоннеля
- `/zoneN/session/<num>/guest/<idx>/pos [zx_rel zy_rel zx_abs zy_abs x y beacon]` — позиции 30 Гц, **номер сессии в адресе**
- `/zoneN/unassigned/<beacon>/pos [...]` — бикон без сессии (виден, но ничей)
- `/zoneN/start|restart [uuid]`, `/zoneN/reset`, `/zoneN/count [n]`, `/zoneN/prompt/enter [uuid guest y_rel]`

Зона N → мастеру (`10.10.10.10:12000`): `/zoneN/sound/<trig> [args]` — звуковой триггер; `/zoneN/prompt/exit [uuid guest y_rel]` — промпт уходит из зоны, мастер передаёт его зоне N+1 как `prompt/enter`.

## Геометрия тоннеля

Тоннель **15 × 3 м**, четыре равные зоны. **Движение справа налево**: гости входят при больших `x`, зона 1 — вход справа, зона 4 — выход слева.

| Зона | x (вдоль, м) | y (поперёк, м) |
|---|---|---|
| 1 (вход) | 11.25 – 15.00 | 0 – 3 |
| 2 | 7.50 – 11.25 | 0 – 3 |
| 3 | 3.75 – 7.50 | 0 – 3 |
| 4 (выход) | 0.00 – 3.75 | 0 – 3 |

Правка: пары `Tunnellength` / `Tunnelwidth` на `zones` + пульс **Equalsplit** пересобирают таблицу поровну. Зоны не обязаны быть равными — границы можно править руками прямо в `zones_table` (это источник истины; повторный Equalsplit правки затрёт). Визуализация и все расчёты следуют за таблицей автоматически.

**Калибровка:** `Origin` — координата BlackTrax, попадающая в угол тоннеля (0,0); `Invertx`/`Inverty` — развороты осей. Сейчас там демо-значения под тестовую запись подрядчика (она снята в комнате 4×3 м) — **на площадке замерить и поставить свои**.
